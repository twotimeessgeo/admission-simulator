# twotimess calculator

브라우저에서 동작하는 2027학년도 9월 모의평가 기준 정시 지원 탐색기입니다. 점수 계산은 Web Worker 안의 Python 런타임에서 실행되며, 입력한 성적은 서버로 전송하지 않습니다.

- 과목별 백분위와 등급: 한국교육과정평가원 2027학년도 9월 모의평가 채점 결과
- 누적 백분위: 공식 과목별 표준점수 도수로 만든 자체 모형
- 합격선: 대학어디가에 공개된 2026학년도 정시 일반전형 환산점수 70% 컷을 자체 모형으로 2027학년도 점수에 옮긴 값. 공개 컷이 없는 모집단위는 합격선을 표시하지 않습니다.
- 대학별 환산식과 변환표준점수: 12월 대학 발표 전 기준의 참고용 계산식

모집단위의 기준선 지수는 합격확률이 아닙니다. 지원 자격과 최종 모집요강은 반드시 대학 발표 자료로 확인해야 합니다.
