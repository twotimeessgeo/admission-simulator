# 정시 지원 찾기

브라우저에서 동작하는 2027학년도 6월 실채점·9월 가채점 정시 지원 탐색기입니다. 점수 계산은 Web Worker 안의 Python 런타임에서 실행되며, 입력한 성적은 서버로 전송하지 않습니다. 성적표의 변환 표준점수는 선택한 대학의 과탐·사탐 원본 표에서 읽으며, 환산식의 가중치와 가산점은 포함하지 않습니다.

모집단위의 기준선 지수는 합격확률이 아닙니다. 지원 자격과 최종 모집요강은 반드시 대학 발표 자료로 확인해야 합니다.
